# A Little Universe for Gungun

A responsive, one-page Diwali surprise website with a personal letter, photo gallery, nickname section, animated diyas, floating petals, and a final wish.

## Run locally
Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Upload the project contents to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.

## Photo privacy
The `assets/` folder contains personal photos. The repository `pry-himanshu/abx` was public when checked. Do not upload these photos to a public repository unless the person pictured has agreed to that exposure. Consider making the repository private before uploading the `assets/` folder, or replace the images with consented/public-safe alternatives.

## Notes
- Music is intentionally an optional, subtle generated tone (no external audio file).
